# 🤖 Starfam.AI — Full-Stack AI Chatbot

STARFAM.AI is a modern, fast, and responsive full-stack AI conversational chatbot application. It leverages **Python FastAPI** for the backend, **Groq API** for ultra-fast open-source LLM inference, and clean **HTML/CSS/JS** for an intuitive frontend experience.

## 🌐 Live Demo

- **Frontend Application:** [PIXLE.AI Live App](https://nikhilpagar-np.github.io/PYTHON.AI_CHATBOT-/)
- **Backend Service:** [FastAPI Service on Render](https://pixle-ai.onrender.com/chat)

## ✨ Features

- **High-Speed AI Responses:** Powered by Groq's high-performance LLM infrastructure (`openai/gpt-oss-20b`).
- **RESTful API Backend:** Fast and asynchronous API built with **FastAPI**.
- **Interactive UI:** Clean, modern, dark-themed user interface with real-time response rendering.
- **CORS Enabled:** Configured for cross-origin requests between GitHub Pages and Render backend.
- **Production-Ready Deployment:** Hosted on Render (Backend) and GitHub Pages (Frontend).

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Python 3.10+, FastAPI, Uvicorn
- **AI Integration:** Groq API (`groq` Python SDK)
- **Deployment & Hosting:** GitHub Pages, Render.com
